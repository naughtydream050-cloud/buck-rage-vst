VINTAGE RAWNESS Mac版 FL Studioテストパック

1. ZIPを解凍します。
2. INSTALL.commandを右クリックします。
3. 「開く」を選択します。
4. インストール完了後、FL Studioを起動します。
5. Options → Manage plugins を開きます。
6. Find installed plugins を実行します。
7. VINTAGE RAWNESSをミキサーのエフェクトスロットから使用します。

注意:
このパックはMac FL Studioテスター向けです。
Apple Developer ID署名・notarizationは実施していません。
macOSのバージョンによっては、初回に右クリック→開く、または
「プライバシーとセキュリティ」画面で許可が必要な場合があります。
警告なしで必ず動作することを保証するものではありません。
FL Studio Mac実機での動作確認は未完了です。
