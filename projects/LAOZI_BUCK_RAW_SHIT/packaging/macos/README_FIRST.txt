老子-BUCK RAW SHIT- Mac版 FL Studioテストパック

1. ZIPを解凍します。
2. INSTALL.commandを右クリックします。
3. 「開く」を選択します。
4. インストール完了後、FL Studioを起動します。
5. Options → Manage plugins を開きます。
6. Find installed plugins を実行します。
7. 老子-BUCK RAW SHIT- をミキサーのエフェクトスロットから使用します。

注意:
このパックはApple Developer ID署名・notarization未実施です。
macOSのバージョンによっては初回に右クリック→開く、または
「プライバシーとセキュリティ」で許可が必要な場合があります。
警告なしで必ず動くものではありません。
